# Placement-verification dataset 2026-09-14.1

This is the reviewed top-camera dataset used by placement-verification model
`2026-09-14.1`.

It contains 122 included records: 101 for training and 21 for evaluation. The
labels cover empty targets, flat components, and multiple components. There
are no on-edge examples.

The package contains the merged final ground-truth manifest, reviewed images,
review decisions, and review provenance. Its audit directory contains the
prior merged dataset used to form this version. It excludes model training
outputs.

The data comes from one machine and a small number of boards. Use independent
boards and sessions before model approval.
