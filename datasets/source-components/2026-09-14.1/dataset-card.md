# Source-component dataset 2026-09-14.1

This is the reviewed feeder dataset used by source-component model
`2026-09-14.1`.

It contains 213 records. Of these, 201 are included: 161 for training and 40
for evaluation. The labels cover empty pockets, flat components, and on-edge
components. The evaluation split has no on-edge component.

The package contains the final ground-truth manifest, reviewed images, review
decisions, carried labels, and review provenance. The package excludes model
training outputs.

The data comes from one machine and a small number of capture sessions. Use a
new independent capture before model approval.
